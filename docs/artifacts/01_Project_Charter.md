# Project Charter
## Project
Context Assembly Framework (CAF)

## Objective
Build an internal web application to collect structured user inputs, convert them into context objects, assemble deterministic instructions, and manage versions, variants, feedback, and audit trails.

## In Scope
- Question Engine
- Context Builder
- Instruction Assembly
- Versioning
- Variants
- Feedback
- Iteration Control
- SQLite/JSON persistence

## Out of Scope
- AI/LLM integrations
- Autonomous optimization
- Recommendation engines
- Business-specific rules

## Success Criteria
- Deterministic instruction generation
- Complete traceability
- No autonomous behavior
