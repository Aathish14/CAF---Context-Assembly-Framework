# Project Glossary

| Term | Definition |
|------|------------|
| **Audit Trail** | A complete, immutable history of all user actions, regenerations, versions, and variants to ensure full traceability and accountability. |
| **CAF** | Context Assembly Framework. An internal infrastructure platform for structuring, assembling, and tracking deterministic instructions. |
| **Context** | A normalized, structured data object representing the user's validated answers. It contains standard fields like objective, audience, and tone. |
| **Context Builder** | The module responsible for receiving raw answers, validating them against the schema, and producing a normalized Context Object. |
| **Deterministic Assembly** | The process of generating an output where the same inputs and templates will mathematically and logically produce the exact same instruction string every single time, without randomness or AI interpretation. |
| **Feedback** | Explicit user signals (such as 1-5 ratings and descriptive tags) stored independently and linked to specific instruction versions for later analysis. |
| **Instruction** | The final, assembled string of text generated by merging a Context object with a Template. |
| **Instruction Assembly Engine** | The module that performs deterministic substitution of context values into placeholders within an instruction template. |
| **Iteration** | A user-initiated cycle of modifying a context or template to regenerate a new instruction, forming a tracked chain of parent-child relationships. |
| **Normalization** | The process of converting unstructured or raw user inputs into a strictly defined, schema-compliant data structure (Context Object). |
| **Question** | A configuration-driven input prompt defined in JSON, specifying expected input type, label, requirement flags, and conditional logic. |
| **Question Engine** | The module that parses JSON question schemas and dictates to the UI what fields should be rendered and when. |
| **Risk Level** | A specific required field in the context schema (low, medium, high) determining the sensitivity or impact of the assembled instruction. |
| **Template** | A static, human-readable structural blueprint containing placeholders (e.g., `{{objective}}`) that dictate how context variables are formatted into an instruction. |
| **Variant** | A structural or ordering alternative of an instruction that shares the exact same base context as its parent. Variants are lateral options, not sequential edits. |
| **Version** | An immutable snapshot of an instruction at a specific point in time. Any manual edit or regeneration results in a new version linked to the prior one. |
